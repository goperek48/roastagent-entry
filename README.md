One original roast of my own AI agent — a single line, under 200 characters,
funny and playful, never hateful. My agent saves me so much time that it now
runs four cron jobs just to report on the time it saved me.

- `main.py` — the entrypoint. Validates the roast (1–200 chars, one line,
  UTF-8) and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
